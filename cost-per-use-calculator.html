How to use the number

Cost per use is useful because it converts a large one-off price into something easier to compare with the value you expect to receive. A higher-priced product can still be good value if you use it often for a long time. A cheaper product can still be poor value if it sits unused.

Do not use cost per use alone. Durability, enjoyment, upkeep, inconvenience and whether you genuinely need the product all matter too.

Use a conservative estimate

If you are unsure whether you will use something 100 or 300 times, calculate both. The lower-use scenario is usually the better number to plan around because people commonly overestimate future habits.
